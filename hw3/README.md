## Running the Code

Run the notebook cells **in order from top to bottom**. Each step depends on the output of the previous one.

### Step 1 — Face De-Identification

```python
from step1_deidentification import *

images, labels = load_images()
plot_pixelization_results(images, block_sizes=[4, 8, 16])
plot_blur_results(images, kernel_sizes=[15, 45, 99])
plot_metrics_summary(images, block_sizes=[2, 4, 8, 16], kernel_sizes=[15, 45, 99])
save_processed_dataset(images, labels, out_dir='processed_faces')
```

**Output:**
- `step1_pixelization.png`
- `step1_gaussian_blur.png`
- `step1_metrics.png`
- `processed_faces/` folder with 7 dataset variants

### Step 2 — CNN Re-Identification Attack

```python
from step2_attack import *

results = run_attack(
    processed_dir='processed_faces',
    num_epochs=50,
    batch_size=32,
)
print_results_table(results)
plot_attack_results(results)
plot_loss_curves(results)
```

**Output:**
- `step2_attack_results.png`
- `step2_loss_curves.png`
- Accuracy table printed to console

> **Note:** Trains 7 CNN models. Expected runtime ~10–20 min (CPU) or ~3–5 min (GPU).

### Step 3 — Differential Privacy Defense

```python
from step3_defense import *

save_dp_dataset(
    images, labels,
    epsilons=[0.1, 0.5, 1.0],
    block_size=16, kernel_size=99,
    out_dir='processed_faces'
)

dp_results = run_dp_attack(
    processed_dir='processed_faces',
    epsilons=[0.1, 0.5, 1.0],
    num_epochs=50,
    batch_size=32,
)
print_dp_results_table(dp_results)
plot_dp_attack_results(dp_results)
plot_dp_metrics(images, epsilons=[0.1, 0.5, 1.0])
plot_dp_visual_comparison(images, epsilons=[0.1, 0.5, 1.0])
```

**Output:**
- `step3_attack_results.png`
- `step3_dp_metrics.png`
- `step3_dp_visual.png`
- Accuracy table printed to console

> **Note:** Trains 8 additional CNN models. Expected runtime similar to Step 2.

## Dataset

The [Olivetti (AT&T) Face Database](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_olivetti_faces.html) is downloaded automatically via scikit-learn on first run. No manual download is required.

- 40 subjects × 10 images = 400 total images
- Image size: 64×64 pixels, grayscale
- Train/test split: 8 images per subject for training, 2 for testing
